# CMPUT 350 HW 1

## AI use disclosure

We used AI to help write the documentation. We reviewed every AI-generated documentation to make sure it is accurate. All code in the project was written by the team except for the Rect vs Rect collision detection (see GameEngine::HandleCollision)

Additionally, AI (Claude, Gemini) was used to generate Bezier curves for enemy spawn waves and attacking, and the ship design + colours. The AI was provided with the dimensions of the screen and the completed Point2D/Rect structs to generate points and rectangles.
